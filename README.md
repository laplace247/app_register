# Interfaz de Login en Kotlin

Aplicación Android desarrollada en Kotlin utilizando Jetpack Compose para gestionar el acceso de usuarios, con integración a la API de Gandi.

## 🛠️ Tecnologías

- **Lenguaje**: Kotlin
- **UI Framework**: Jetpack Compose
- **Diseño**: Material 3
- **Networking**: Ktor Client
- **IDE**: Android Studio
- **Configuración mínima**: Android SDK 24+

## 🚀 Características principales

- **Interfaz moderna**: Implementada con componentes de Material 3.
- **Autenticación**: Integración con API externa mediante Ktor.
- **Navegación**: Uso de `androidx.navigation.compose` para una navegación fluida.
- **Seguridad**: Soporte para JWT (`java-jwt`) para el manejo de sesiones.

## 📱 Estructura del proyecto

El proyecto está organizado como un módulo de Android:
- `/LoginUI/app`: Código fuente principal, vistas de login y lógica de red.
